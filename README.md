# Аналитические проекты · Анастасия Щугарева

Продуктовый и UX-аналитик. Здесь собраны учебные проекты по задачам VK и VK Education, 2024–2026: A/B-тесты, продуктовое discovery, модели рынка, машинное обучение на текстах, качественные исследования.

Каждый проект — Jupyter-ноутбук с сохранёнными результатами. Графики, таблицы и выводы видны прямо на GitHub, ничего запускать не нужно.

| [Родитель на Учи.ру: из наблюдателя в участника](<Вовлечение родителя в образование ребенка/uchi-parent-discovery/>) | Discovery-исследование родителя на образовательной платформе. По логам выяснилось, что 58% входов в родительский аккаунт делает ребёнок. Сегментация родителей, дерево метрик, мини-сервис «Семейный пульс» с кликабельным прототипом. Completion +1,2 п.п., retention 7-го дня +5 п.п., время до первого результата короче на 25 часов. В 10–11 классах эффект меняет знак. | Python, SciPy, statsmodels |

| [CustDev: студенты на практике](<student_internship_custdev.ipynb>) | Качественное исследование по брифу VK Education: гипотезы, квоты выборки, кодирование интервью по темам, ранжирование болей, эмоциональная кривая пути студента (CJM). | Python, pandas, matplotlib |
